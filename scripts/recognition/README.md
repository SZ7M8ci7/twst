# スクショから手持ちを取り込む

手持ち設定の「スクショから取り込む」で PNG / JPEG / WebP を複数選択し、認識結果を確認して反映します。その後、既存の「保存」で確定します。画像の解析・照合・レベルOCRはブラウザ内で行い、スクショはサーバーへ送信しません。

## 画像と辞書の更新

主な取得元は日本語Wiki（https://twst.wikiru.jp/）です。カード一覧から新規ページを見つけ、ページURLでカードを対応付けます。不足画像はGamerchの日本語カード一覧から、レア度・キャラクター・衣装名が一致するページだけ補完します。通常・グルーヴィー後は同じカードIDとして扱います。既存アプリのアイコンも補助テンプレートとして使用します。

GitHub Actionsは1日1回、日本時間04:17（UTC 19:17）に更新します。新規カード・未取得の絵柄・必要情報の掲載待ちだけを確認し、取得済みの画像と判定データは再利用します。全カードが取得済みで新規追加もなければ、確認対象は主Wikiの一覧ページ1件です。通常のコード公開では公開済み辞書を再利用し、再利用できる辞書がない場合だけ構築します。

一覧・未完了カードページのHTTPキャッシュは24時間有効です。取得済み画像には期限を設けません。取得は直列で、主Wikiは通信開始を1秒以上空け、Gamerchは各通信前に1秒待機します。429・503応答後はその取得元への通信を終了します。既存画像の差し替え確認は行いません。

取得完了の判定には公開済み辞書を使うため、画像キャッシュが削除されても取得済みの絵を再ダウンロードしません。公開辞書と元画像キャッシュの両方を失った場合や、互換性のない抽出形式に変更した場合は再構築が必要になることがあります。

新カードは必要な能力値・魔法・バディ情報が揃ってからカタログへ追加します。既存IDと手持ち保存キーを維持します。画像取得失敗時は既存の判定データを維持し、更新全体が失敗した場合は利用可能な以前の辞書を使用します。

画像全体からORB特徴点を抽出し、一覧アイコンを部分画像として照合します。手動でカードごとの切り抜きを作る処理はありません。公開するのは数値特徴量・カード情報・出典URLで、外部サイトのカード全体絵は配信しません。新カードの画面表示用アイコンがアプリ素材にない場合は未掲載画像を表示します。

辞書はSHA-256で内容を識別し、特徴量を64分割します。ブラウザは解析開始時に最新版を確認し、初回以降は変更された分割だけ取得します。サイズとハッシュを検証してから使用し、取得に失敗した場合は保存済みの完全な辞書へ戻ります。更新レポートには確認対象ページ・省略した完了ページ数・取得エラーを記録します。

## 取り込みと編集

元画像の切り抜きと認識したアイコンを並べ、Lv・凸数を同じ画面で修正します。アイコンから既存のカード選択モーダルを開けます。フィルターの画面構成は既存のままで、取り込み用の絞り込み状態を通常の設定へ書き込みません。確認が必要な箇所のみの表示を初期状態とし、PCでは最大6列で表示します。

「取り込むレベル」は最大レベルが初期値です。現在レベルへ切り替えると、表示・重複チェック・反映する値も切り替わります。OCRは左側を現在レベル、右側を最大レベルとして保持し、手修正は選択肢ごとに保持します。選択した側が読めない場合は保存済みレベルを維持します。

レベル表示と限界突破表示のスクショは一緒に選択できます。限界突破表示ではカード下の4つの丸を検出し、紫の丸の数を0〜4凸として読み取ります。同じカードIDのレベル情報と組み合わせ、両方の画像の結果欄にも補完した値を表示します。丸から直接読んだ凸数を推定値より優先し、手動修正はさらに優先します。限界突破画像同士で凸数が異なる場合は確認対象に残します。限界突破画像だけのカードはレベルを推測せず、保存済みレベルを維持します。

丸表示がない場合は、黒枠を4凸、非黒枠でM3解放を3凸と判定します。SSRのM3未解放時だけ、最大レベル80〜84を無凸、106〜110を2凸と判定します。それ以外の不明は0凸として反映します。手動修正した凸数を保持し、同じカードの重複で値が矛盾する項目は更新を保留します。

取り込みは写っているカードの所持を追加し、写っていないカードを変更しません。取り消しでは今回変更した設定を復元しますが、取り込み後に別途編集したカードは対象から外します。

画像の選択枚数に上限はありません。各画像は30MB・2400万画素・一辺24000pxまで、検出領域は画像あたり300個までです。

## 共有用の一覧画像

「一覧画像を作成」の専用モーダルで、画像をドラッグして順序を変更します。PCは大きな2列、狭い画面は1列で表示し、タッチの長押し・矢印キー・端での自動スクロールにも対応します。

出力には元画像のカード絵・属性・Lv帯を使用し、ヘッダー・余白・途中で切れた行を除きます。画像間の重複はカードIDと絵の画素から判定します。6列に整列し、270枚を超える場合は複数PNGに分割します。取り込み時に修正したLv・凸数を元画像へ描き直す処理はありません。

## ローカル実行

```sh
npm ci --legacy-peer-deps
python -m pip install -r scripts/recognition/requirements.txt
python scripts/recognition/update.py
npm run dev
```

本番ビルドは `npm run build` です。`predev` / `prebuild` でOCR実行データをパッケージからコピーし、アプリと同じサイトから配信します。辞書の抽出条件を変える場合はPythonとTypeScriptの `EXTRACTOR` を同時に変更します。
