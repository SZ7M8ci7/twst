# 中国語（簡体字）の翻訳方針

## 対応範囲

`zh-CN` を日本語・英語と並ぶ選択肢として追加。画面の既存翻訳キー、カード・衣装・魔法効果の表示、衣装検索、Vuetifyの組み込み文言に対応する。繁体字は別途翻訳が必要なため、簡体字への自動判定に含めない。未設定時は従来どおり日本語。選択言語のみ `twst-language` に保存する。

外部サイトへのリンク先（客房関連ツールなど）はこのリポジトリの翻訳対象外。自由入力の文章を翻訳する機能はなく、表示変換は辞書に登録した語句に限定する。

## 固有名詞の扱い

- 人名の表示は英字を採用。内部IDの `lolo` はRollo、`train` はTreinとして扱う。内部IDは変更しない。
- 上表で確認した衣装以外は、本ツールの暫定訳または原語由来の表記。例えばUnion/Bloom、La Bonbonnière、Friendly Techは識別用の語を残す。新衣装の名称を公式訳・コミュニティ統一訳と断定しない。
- 暫定訳の例：アップル・ボア→苹果绒毛服、ビッグ・チェック→大格纹服。異なる衣装を一つの名称にまとめない。
- 誕生日衣装は `birthN` ではなく日本語の `costume` を照合する。ユニオン・ブルーム・プラチナを内部IDから推測して取り違えない。
- `zh-CN-game.json` に登録していない新衣装は、日本語原名を保持。確認後に辞書と本資料を更新する。

## 実装・検証

- `src/i18n/zh-CN.json`：画面文言。既存の693キーと埋め込み変数を維持。
- `src/i18n/zh-CN-game.json`：84種類の衣装・寮・戦闘用語。表示時のみ変換。
- 保存データ、フィルターの値、計算式、カードの日本語マスターデータは変更しない。
- 衣装検索は日本語・英語・簡体字のいずれでも一致し、言語切替後も検索を維持する。
- `npm run test:i18n`：キーと変数の一致、全衣装・効果の網羅性、名前の整合、表示のみの変換、検索、言語保存、既存言語の回帰を検査する。

今回の確認結果：翻訳テスト8件・`tsc --noEmit`・`npm run build`成功。ブラウザーで言語切替、再読み込み後の言語維持、配隊検索の「卧室小憩」による絞り込みと他言語への切替を確認。

追加の`vue-tsc --noEmit`では、今回未変更の`SimChart.vue`と`examSimulator.vue`に型エラーが残る。通常ビルドには影響しないが、Vueテンプレートを含む型検査を通すには別途修正が必要。
