USER GUIDE / 一般利用者向け

ツイステツール置き場
利用手順書

初めて使う人向けの簡易ガイドです。試験で使う編成を探し、結果を確認する大まかな流れだけを記載します。

手持ちを登録→編成を探す→試験で確認→保存する

1. まず手持ちを登録する

  • 左上のメニューから「手持ち設定」を開く。
  • 持っているカードの「所持」にチェックを入れる。
  • カードの「Lv」と「凸数」を入力する。
  • 「保存」を押す。
  • スクショから登録する場合は「スクショから取り込む」を使う。
  • 初めての利用では、取り込み後に内容を確認して「保存」を押す。

2. 試験を選ぶ

  • メニューの「試験」→「試験シミュレータ」を開く。
  • 「通常試験」または「統一試験」から対象の試験を選ぶ。
  • 過去の試験は「過去分」から選ぶ。
  • 「試験条件」で敵属性・難易度・敵HP・特別課題を確認する。

3. 編成を探す

  • 「編成探索」タブを開く。
  • 必ず入れたいカードがあれば「カード指定」で選ぶ。
  • 必ず入れたいキャラクターがあれば「キャラ指定」で選ぶ。
  • 「探索条件を変更」で追加凸と挑戦回数を設定する。
  • 手持ちのまま探す場合は追加凸を0にする。
  • 「編成探索」を押す。
  • 結果の5枚、追加凸、最高スコア、95パーセンタイルを確認する。
  • 候補を詳しく見るときは「詳細シミュレーション」を開く。
  • 通常試験は自前5枚、統一試験は自前4枚とサポート1枚が基本です。

4. 編成をシミュレーションする

  • 「詳細シミュレーション」→「編成」で5枚、Lv、凸、使用魔法を確認する。
  • 「行動」で自分の行動パターンを設定する。
  • 自動で試す場合は「シミュ」→「自動最善」を選ぶ。
  • 自分で設定した行動を試す場合は「通常」を選ぶ。
  • 回数を入力して「実行」を押す。
  • 「スコア分布」「達成確率」「リタイア理由」「ログ」を確認する。
  • 条件を変えるときは、試験条件・編成・行動を見直して再実行する。

5. 結果を保存する

  • 残したい編成は「編成」から名前を付けて保存する。
  • 保存されるのは編成と行動設定です。試験条件や実行結果は別に確認する。
  • 手持ち設定は「データ」→「JSON保存」でバックアップする。
  • 別の環境で使うときは「JSON読込」後に「保存」を押す。
  • デッキ探索ツールで登録したLv・凸数を使うときは、「検索設定」の探索対象で「手持ち」を選んで「探索開始」を押す。
  • 「必須カード」で衣装まで指定できる。「必須キャラクター」と併用すると、両方の条件を満たす編成を探せる。

6. 困ったとき

  • カードが候補に出ないときは、手持ち設定の所持・Lv・保存状態を確認する。
  • デッキ探索で最大Lv・完凸の編成を試すときは、「手持ち内全カード完凸」または「全カード完凸」を選ぶ。
  • 「許容組み合わせなし」と出たら、「行動」で候補を増やすか「自動最善」を使う。
  • すべてリタイアするときは、HP・回復・敵条件・特別課題を確認する。
  • 探索に時間がかかるときは、対象カード・結果上限・挑戦回数を減らす。
  • 画面が狭いときは、表を横にスクロールする。

画面名や表示内容は、公開版の更新により変わる場合があります。
